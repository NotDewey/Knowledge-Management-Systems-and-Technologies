# Knowledge Management Systems and Technologies

This repository contains the projects, activities, and practical implementations developed throughout the **Knowledge Management Systems and Technologies** course at Tecmilenio University.

The main objective is to explore how organizations create, organize, share, and apply knowledge, as well as how technologies such as Artificial Intelligence, Machine Learning, and information retrieval systems can improve these processes.

## About the Course

Knowledge management focuses on making information and experience accessible and useful within an organization.

Throughout this course, we explore concepts such as:

- Knowledge Management Life Cycle
- Tacit and Explicit Knowledge
- Organizational Knowledge Structures and Ontologies
- Artificial Intelligence in Knowledge Management
- Automated Document Classification
- Semantic Information Retrieval

The goal is not only to understand these concepts theoretically, but also to apply them through practical projects.

## Projects

### 01. Project Progress — Knowledge Management System Prototype

**Fictional Company:** Nexo IT Services

This project focuses on designing and implementing a knowledge management system prototype for a fictional IT services company.

The system demonstrates how organizational knowledge can be structured, automatically classified, and retrieved using Machine Learning and Natural Language Processing techniques.

**Main Features:**
- Organizational knowledge life cycle representation.
- Knowledge ontology and conceptual relationships.
- Automatic document classification using TF-IDF and Logistic Regression.
- Semantic information retrieval using TF-IDF and Cosine Similarity.
- Python-based implementation with reproducible tests and supporting evidence.

**Project Directory:** [`Project-Progress-KM/`](./Project-Progress-KM/)
