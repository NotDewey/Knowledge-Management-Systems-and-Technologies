Objective
Recommend five related documents from the Nexo IT Services corpus using TF-IDF and cosine similarity.

Dependencies
Python 3.12, NumPy and scikit-learn.
Install the libraries with: python -m pip install numpy scikit-learn

Execution
Open a terminal in this folder and run either command below.

Usage examples
python recommender.py --id DOC002
python recommender.py --query "restore deleted customer files after a failed backup"

The evidencias/activity3 folder contains the three test logs and screenshots.
